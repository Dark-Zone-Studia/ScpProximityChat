# 🗣️ ScpProximityChat
**ScpProximityChat** — это плагин для [Exiled](https://github.com/Exiled-Team/EXILED), который позволяет игрокам на ролях SCP общаться с людьми (и другими SCP) через бесконтактный голосовой чат (Proximity Chat)

Больше никаких молчаливых убийц! Теперь SCP могут запугивать жертв, договариваться или просто отыгрывать роль (RP) с помощью голоса.

### ✨ Основные возможности
*   🎙️ **Голосовой чат для SCP:** Позволяет SCP говорить так, чтобы их слышали все игроки поблизости.
*   ⚙️ **Гибкая активация:**
    *   **Меню настроек (рекомендуется):** Игроки могут назначить клавишу переключения чата прямо в меню игры (`Esc` -> `Настройки` -> `Server Specific`).
    *   **NoClip:** Альтернативный режим активации через клавишу NoClip (обычно `Alt`).
*   🔊 **Настройка звука:** Полный контроль над громкостью, минимальной и максимальной дистанцией слышимости.
*   📝 **Кастомизация:** Настраиваемые сообщения (Hints/Broadcasts) при включении и выключении чата.
*   🎭 **Выбор ролей:** Вы сами решаете, каким SCP разрешено говорить (по умолчанию: 049, 096, 106, 173, 939 и др.).
*   🔇 **Режим изоляции:** Опция `UseDefaultScpChat` позволяет выбирать — слышат ли SCP свой канал (Scp Chat) во время разговора с людьми или нет.

### 📥 Установка
1. Скачайте файл `ScpProximityChat.dll` из раздела [Releases](ссылка_на_ваш_релиз).
2. Поместите файл в папку `%AppData%\EXILED\Plugins` (на Windows) или в соответствующую папку на вашем сервере.
3. Перезапустите сервер.

### ⚙️ Конфигурация
Конфиг создается автоматически в `EXILED/Configs/Port-config.yml`.

Пример стандартной конфигурации:

```yaml
scp_proximity_chat:
  is_enabled: true
  debug: false
  # Тип активации: ServerSpecificSettings или NoClip
  activation_type: ServerSpecificSettings
  # Роли, которым доступен чат
  scp_roles:
  - Scp049
  - Scp0492
  - Scp096
  - Scp106
  - Scp173
  - Scp939
  # Если true, SCP могут использовать и обычный чат, и Proximity одновременно
  use_default_scp_chat: true
  volume: 10
  min_distance: 2
  max_distance: 10
  # ID настройки (не меняйте, если не знаете зачем)
  keybind_id: 200
